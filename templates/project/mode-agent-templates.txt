Agent run-file template (agents/template.json — omit conversation_id for a fresh conversation per run; add "watchAgents": ["<set>.*"] for a master agent that supervises others with check_agents):
```json
{
  "conversation_id": "<set>.<role>",
  "agent": "<set>.<role>",
  "profile": "local",
  "systemDataPrompt": "Read agents/<role>.md and follow its instructions strictly.",
  "prompt": "Run the scheduled task.",
  "maxSteps": 40,
  "timeout": 600
}
```

Agent launcher template (agents/template.sh):
```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/.."
set +e
# stderr carries "[run] conversation_id=<id> new=true|false" even with --log off: keep it to follow the run.
zerochat --run-file "agents/<role>.json"
rc=$?
set -e
# 0: completed, 5: needs_input (answer in ZeroChat's Pending tasks view; resumes with stored launch), 6: limit reached,
# 7: this conversation is already running (overlapping cron), nothing was launched
exit "$rc"
```
