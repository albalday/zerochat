## M90 Reorganización del panel MCP

Goal: hacer el panel Ajustes › MCP compacto, claro y fácil de recorrer mediante secciones y tarjetas plegables (`<details>`), separando las herramientas locales del host de las herramientas de cada servidor MCP externo (que pasan a vivir agrupadas dentro de la tarjeta de su propio servidor).
Done when: las tareas de M90 están implementadas con todos los niveles de §4 (incluido `npm run test:browser` y `test:architecture`) en verde.
- [x] M90-T1 Secciones plegables en el panel Ajustes › MCP y separación de herramientas locales del host (js/ui-settings.js, js/ui-mcp.js, js/i18n.js, css/components/tools.css): (1) convertir las secciones de #settings-mcp («Servidores MCP Disponibles» y «Herramientas locales del servidor») en tarjetas plegables <details class="mcp-status-card settings-collapsible-card"> coherentes con #settings-permissions (con contador en la cabecera: activos/total de servidores y total de herramientas locales); (2) hacer que #mcp-tools-container muestre únicamente las herramientas locales del host (state.tools, excluyendo state.externalTools) con título e i18n propios en español e inglés; y (3) ocultar la tarjeta de servidores cuando no haya conexión para dejar solo el estado y la tarjeta de arranque (2026-11-25)
- [x] M90-T2 Agrupar las herramientas de cada servidor MCP externo dentro de su propia tarjeta plegable (js/ui-mcp.js, js/ui-settings.js, js/i18n.js, css/components/tools.css): (1) diseñar cada tarjeta de servidor externo con una cabecera compacta siempre visible (nombre, insignia de estado, contador de herramientas/activas, botón de confiar y botón Iniciar/Detener) y un cuerpo plegable (<details>) que agrupe descripción, enlaces de ayuda/transporte remoto, banners de error/OAuth, secretos, opciones y una subsección plegable propia con las herramientas de ese servidor (filtradas de state.externalTools por metadata.mcpServerId), mostrando su nombre original corto, política de autorización e interruptor; (2) preservar el estado abierto/cerrado de cada <details> entre re-renders provocados por el latido, cambios de opciones, secretos o políticas (manteniendo abiertos automáticamente los servidores con error o OAuth pendiente); y (3) asegurar que los eventos delegados en #mcp-servers-list gestionan cambios de .mcp-auth-select y .mcp-tool-checkbox de las herramientas anidadas y que gatherSettingsFormConfig recoja también los interruptores dentro de #mcp-servers-list (2026-11-25)
- [x] M90-T3 Compactar el diseño visual de tarjetas de herramientas y servidores MCP y añadir pruebas de navegador (css/components/tools.css, js/ui-mcp.js, tests/browser/): (1) hacer más legibles y compactas las filas de herramientas (descripción en 1–2 líneas, parámetros solo visibles al desplegar o en línea discreta, controles alineados en una sola fila y buen comportamiento en móvil); (2) añadir/actualizar pruebas en tests/browser/ y tests/unit/ o tests/integration/ cubriendo el plegado de secciones, la separación de herramientas locales frente a las agrupadas en cada servidor externo, la persistencia del estado desplegado tras re-render y el guardado de interruptores/políticas desde las herramientas anidadas; y (3) verificar npm run test:architecture (incluyendo CSS e i18n sin huérfanos) y npm run test:browser (2026-11-25)
