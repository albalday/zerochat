## M28 Quiet public presence: minimal discoverability
Goal: Make the GitHub Pages site (https://albalday.github.io/zerochat/) quietly discoverable: a short descriptive landing page, unique title/description per public page and a generated sitemap, with no marketing infrastructure, no promises and no active SEO follow-up.
Done when: the site root serves a short static bilingual landing page (descriptive tone, no promises, no version number) instead of the Jekyll-rendered README; every public page (landing, zerochat.html, help ES/EN) has a unique title and meta description, checked by an architecture test; sitemap.xml (URLs only, no lastmod) is generated by an npm script from the real page list and a test fails when its URL set is stale.
