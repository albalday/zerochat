## M19 Web image ingestion and multimodal analysis
Goal: Allow vision-capable models to fetch, ingest and visually inspect images from the web (from search results, web pages or direct URLs) as multimodal input, in the same way documents (PDF/Office) and RAG images are ingested.
Done when: the model can download an image via its URL (evaluating similarities/unification with download_doc vs. a dedicated download_image tool), validate and sanitize its MIME type and size limits, feed it as a safe base64 dataUrl into the multimodal turns for vision providers (Gemini, Anthropic, OpenAI, local vision models), show the corresponding preview card in the chat, with unit/integration/browser tests and /help (ES/EN) updated.
- [x] M19-T1 Evaluate similarities with download_doc: decide whether to extend download_doc or create a dedicated download_image tool, reusing web-browser fetch, card infrastructure and vision checks (2026-10-16)
- [x] M19-T2 Implement safe web image fetching and ingestion (URL resolution, MIME validation for PNG/JPEG/WebP/GIF, size limits, base64 dataUrl conversion) (2026-10-16)
- [x] M19-T3 Implement tool card and UI integration (live spinner, thumbnail preview, open in tab) and inject extracted images into turn multimodal message inputs (2026-10-16)
- [x] M19-T4 Verify provider adapters (Gemini, Anthropic, OpenAI, local vision) handle web image payloads as multimodal input (2026-10-16)
- [x] M19-T5 Tests (unit, integration, browser) covering edge cases (404, invalid type, oversize, valid images) and update /help (ES/EN) (2026-10-16)
