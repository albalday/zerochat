## M33 Live MCP state from the local server
Goal: Every piece of MCP state that can change during a session (external services and their tools, Playwright installation) has a single source in ChatState kept current by the local server, so no panel or tool decides on a stale snapshot or on a second check that can disagree.
Done when: the plan below has been reviewed and simplified before any code (fewer tasks, fewer moving parts, reuse of the existing heartbeat and syncExternalServers); a crashed external service is reported as stopped/error, not running; a service started, stopped or crashed outside this tab reaches mcp.externalServers and mcp.externalTools without reconnecting; the heartbeat is the only periodic read of live MCP state; all applicable suites pass.
