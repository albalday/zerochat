ZeroChat

Qué es

ZeroChat es un cliente web de uso personal para conversar con modelos de IA, consultar documentos y usar herramientas. Se ejecuta en el navegador y guarda el historial en el propio navegador; un servidor local opcional en Python añade acceso a archivos, comandos y servicios MCP.

Es un proyecto personal de código abierto con licencia MIT.

What it is

ZeroChat is a personal web client for chatting with AI models, consulting documents and using tools. It runs in the browser and keeps the history in the browser itself; an optional local Python server adds file access, commands and MCP services.

It is a personal open source project under the MIT licence.
