ZeroChat

Qué es

ZeroChat es un entorno personal y privado para trabajar con modelos y agentes de IA. Funciona al instante en el navegador con chat multimodelo, WebLLM y RAG local; un servidor local opcional en Python añade proyectos con ficheros, consola, servicios MCP, ejecución CLI y orquestación desatendida de agentes con supervisión humana.

Es un proyecto personal de código abierto con licencia MIT.

What it is

ZeroChat is a personal, private workspace for working with AI models and agents. It runs straight in the browser with multimodel chat, WebLLM and local RAG; an optional local Python server adds project files, shell commands, MCP services, CLI runs and unattended agent orchestration with human supervision.

It is a personal open source project under the MIT licence.
