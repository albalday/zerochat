### 3.4. Límite de Contenido Externo y HTML

#### ⚠️ HALLAZGO CRÍTICO #3: Uso mixto de innerHTML

**Evidencia:** 15 usos de `innerHTML` detectados:

**Casos seguros (HTML confiable generado por código):**
1. `js/utils.js:82` - `setTrustedHtml()` - API documentada para HTML confiable
2. `js/tool-cards.js:81,95,160,196,235,239,245` - Construcción de tarjetas con plantillas internas
3. `js/mcp.js:631,666,671` - Construcción de tarjetas MCP con plantillas internas
4. `js/ui-profiles.js:60` - Limpieza de datalist (`els.profileDatalist.innerHTML = ''`)

**Casos que requieren revisión:**
5. **`js/attachments.js:92,98,117`** - Construcción de chips de adjuntos
   - Línea 117: `chip.innerHTML = <template>`
   - **Análisis requerido:** Verificar si el nombre del archivo (`file.name`) se escapa correctamente

**Riesgo:** Potencial XSS si nombres de archivo maliciosos no se escapan

**Escenario de fallo:**
1. Usuario adjunta archivo con nombre: `"><img src=x onerror=alert(1)>.pdf`
2. Si no se escapa, el navegador ejecuta el script

**Propuesta:**
```javascript
// Antes (potencialmente inseguro):
chip.innerHTML = `<span>${file.name}</span>`;

// Después (seguro):
const chip = document.createElement('div');
chip.className = 'attachment-chip';
const nameSpan = document.createElement('span');
nameSpan.textContent = file.name; // Escape automático
chip.appendChild(nameSpan);
```

**Prueba:** Test de inyección HTML en nombre de archivo adjunto:
```javascript
test('attachment chip escapes malicious filename', () => {
  const maliciousName = '"><img src=x onerror=alert(1)>.pdf';
  // Verificar que el payload se conserva como texto y no ejecuta
});
```

**Prioridad:** **ALTA** (seguridad)

**Detección automática de idioma:**
```javascript
function detectInitialLanguage() {
  // 1. Preferencia guardada en Storage
  const saved = Storage.getStorageItem('language');
  if (saved === 'es' || saved === 'en') return saved;

  // 2. Idioma del navegador
  const browserLang = navigator.language.toLowerCase();
  if (browserLang.startsWith('en')) return 'en';

  // 3. Default: español
  return 'es';
}
```
