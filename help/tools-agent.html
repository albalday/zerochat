Modo Agente y Herramientas Nativas

Convierte a los modelos de lenguaje en asistentes activos capaces de razonar, ejecutar código, buscar información y dibujar gráficos.

1. ¿Qué es el Modo Agente en ZeroChat?

El Modo Agente transforma la interacción pasiva de pregunta-respuesta en un bucle autónomo multivuelta (Agentic Loop).

Cuando planteas una tarea compleja, el modelo evalúa qué herramientas necesita, emite una llamada estructurada (Function Calling), ZeroChat ejecuta la herramienta de forma segura en tu navegador y devuelve el resultado al modelo para que continúe resolviendo el problema hasta completar el objetivo.

Límite de turnos de seguridad (maxAgentTurns): En la configuración puedes definir el número máximo de turnos continuos que el agente puede encadenar (por defecto entre 5 y 10), impidiendo bucles infinitos y consumo desmedido de tokens.

3. Seguridad del Sandbox de JavaScript

La ejecución de código arbitrario generado por un modelo de lenguaje es un vector crítico. En ZeroChat, el ejecutor de JavaScript (sandbox.js) implementa rigurosas medidas de contención:

  • Aislamiento en Web Worker: El código no se ejecuta en el hilo principal ni tiene acceso al objeto window, document, cookies, almacenamiento local ni el árbol DOM.
  • Restricción de APIs peligrosas: Las APIs de red (fetch, XMLHttpRequest, WebSocket) están desactivadas dentro del sandbox.
  • Límites de tiempo (Timeout): Si un script generado contiene un bucle infinito o tarda más de lo estipulado (por ejemplo, 5 segundos), el worker se destruye automáticamente.
  • Límites de memoria y tamaño de salida: Previene bloqueos del navegador por saturación de memoria o cadenas masivas.

4. Tarjetas de Herramientas Interactivas (Tool Cards)

Cuando el agente invoca una herramienta durante una conversación, ZeroChat muestra una Tool Card en el flujo de mensajes que refleja el estado de la operación en tiempo real:

  • Cabecera con estado: Muestra un spinner animado durante la ejecución y un check verde o icono de alerta al terminar.
  • Entrada y salida colapsables: Puedes desplegar la tarjeta para ver los argumentos exactos pasados a la función y el resultado devuelto por la herramienta.
  • Persistencia en historial: Si recargas la página o navegas entre conversaciones, las tarjetas de herramientas se restauran fielmente con sus desplegables operativos.
