Automatización del navegador

Preparar y utilizar browser_action con el servidor local.

browser_action es una herramienta del servidor local que controla Chromium para navegar, hacer capturas, pulsar elementos y rellenar formularios. Necesita Node.js, Playwright y un navegador compatible. En Termux no es posible usar Playwright actualmente, así que esta herramienta no está disponible en Android. No controla la pestaña de ZeroChat ni hereda necesariamente las sesiones de tu navegador habitual. Las capturas válidas se muestran en la tarjeta de la herramienta y se entregan al modelo como evidencia visual.

Preparación

  1. Inicia el backend zerochat o python3 zerochat.py y comprueba que Node.js y npm estén disponibles para ese proceso. En Windows, consulta Instalar Node.js en Windows.
  2. En el capítulo Navegador del perfil elige browser_action o, para las herramientas completas, Playwright MCP: el perfil lo arranca al activarse. Su instalación prepara Playwright y Chromium bajo ~/zerochat/services/playwright/.

La herramienta local browser_action y las herramientas externas de Playwright MCP son interfaces distintas aunque puedan aprovechar las mismas dependencias, pero el perfil elige solo una para evitar automatizaciones duplicadas: aunque Playwright MCP esté en marcha, sus herramientas no se ofrecen si el perfil activo elige browser_action o ninguno. También puede detectarse una instalación de Playwright para Node.js con Chrome, Edge o Chromium. Instalar el paquete Python de Playwright no satisface este requisito.

Si no está disponible, revisa la salida de instalación y los requisitos del navegador en tu sistema. La descarga puede necesitar red y bibliotecas del sistema; instalar el paquete npm por sí solo no garantiza que Chromium arranque.

Privacidad y seguridad: la herramienta puede visitar URLs y ejecutar acciones web indicadas por el modelo. Mantén la política de permisos en “Preguntar” y no automatices cuentas o formularios sensibles sin revisarlos.
