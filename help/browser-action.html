Automatización del navegador

Preparar y utilizar browser_action con el servidor local.

browser_action es una herramienta del servidor local que controla Chromium para navegar, hacer capturas, pulsar elementos y rellenar formularios. Necesita Node.js, Playwright y un navegador compatible. No controla la pestaña de ZeroChat ni hereda necesariamente las sesiones de tu navegador habitual.

Preparación

  1. Inicia el backend zerochat o python3 zerochat.py y comprueba que Node.js y npm estén disponibles para ese proceso.
  2. Para usar las herramientas completas, abre Ajustes → MCP e inicia Playwright MCP. Su instalación prepara Playwright y Chromium bajo ~/zerochat/services/playwright/.
  3. Si browser_action está activa, acepta el aviso de sustitución. ZeroChat la desactiva antes de iniciar Playwright MCP.

La herramienta local browser_action y las herramientas externas de Playwright MCP son interfaces distintas aunque puedan aprovechar las mismas dependencias, pero se ofrecen como alternativas para evitar automatizaciones duplicadas. También puede detectarse una instalación de Playwright para Node.js con Chrome, Edge o Chromium. Instalar el paquete Python de Playwright no satisface este requisito.

Si no está disponible, revisa la salida de instalación y los requisitos del navegador en tu sistema. La descarga puede necesitar red y bibliotecas del sistema; instalar el paquete npm por sí solo no garantiza que Chromium arranque.

Privacidad y seguridad: la herramienta puede visitar URLs y ejecutar acciones web indicadas por el modelo. Mantén la política de permisos en “Preguntar” y no automatices cuentas o formularios sensibles sin revisarlos.
