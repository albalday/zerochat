Automatización del navegador

Requisitos mínimos de browser_action.

browser_action controla un navegador Chromium en segundo plano para navegar, hacer capturas, pulsar elementos y rellenar formularios. Solo se puede activar cuando están disponibles Node.js, Playwright y un navegador Chromium compatible.

Instalación recomendada

  1. Instala Node.js 18 o posterior, que incluye npm.
  2. En ZeroChat, abre Ajustes → MCP y arranca Playwright MCP. ZeroChat descarga Playwright y Chromium en ~/zerochat/services/playwright/.
  3. Vuelve a conectar el servidor local o recarga ZeroChat. Ya podrás activar browser_action.

También puedes usar una instalación de Playwright disponible para Node.js junto con Google Chrome, Microsoft Edge o Chromium. No instales paquetes Python para esta herramienta.

Privacidad y seguridad: la herramienta puede visitar URLs y ejecutar acciones web indicadas por el modelo. Mantén la política de permisos en “Preguntar” y no automatices cuentas o formularios sensibles sin revisarlos.
