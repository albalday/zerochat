Instalar el servidor local

Opcional: archivos del equipo, ejecución de comandos y servicios MCP.

Añade el servidor local

Necesitas Python. Elige una de estas alternativas; ambas abren la web y utilizan ~/zerochat/ para los datos locales.

Instalar desde PyPI (recomendado)

Linux, macOS y Android (Termux):

pip install zerochat
zerochat

Windows (PowerShell o CMD): usa el lanzador py, que funciona aunque la carpeta Scripts de Python no esté en el PATH.

py -m pip install zerochat
py -m zerochat

En los siguientes arranques basta con la segunda línea.

Descargar el script

Linux, macOS y Android (Termux):

curl -fsSL https://albalday.github.io/zerochat/zerochat.py -o zerochat.py
python3 zerochat.py

Windows (PowerShell o CMD): curl.exe viene con Windows 10 y 11; en PowerShell hay que escribirlo con .exe para no usar el alias de Invoke-WebRequest.

curl.exe -fsSL https://albalday.github.io/zerochat/zerochat.py -o zerochat.py
py zerochat.py

En los siguientes arranques, ejecuta python3 zerochat.py (py zerochat.py en Windows) desde la carpeta de descarga. También puedes descargar el archivo a mano.

Mantén el proceso en ejecución y utiliza el enlace que abre. Después ve a Ajustes → MCP para comprobar la conexión y habilitar herramientas.

Entornos probados y compatibilidad de navegador

  • Entornos probados:
    • Linux: distribuciones estándar (x86_64 y ARM) con Python 3.10+. Ejecución de comandos con sesión bash interactiva persistente.
    • Windows: Windows 10 y Windows 11 con PowerShell y lanzador py. La ejecución de comandos se adapta nativamente a PowerShell manteniendo directorio y entorno.
    • Android + Termux: Termux con el paquete python. Abre URLs con termux-open-url. En Termux no es posible usar Playwright actualmente, así que browser_action y Playwright MCP no están disponibles.
  • Compatibilidad de navegador:
    • ZeroChat no funciona con el motor WebKit debido a sus restricciones de acceso a red local (Private Network Access) y de almacenamiento web. Si abres ZeroChat con WebKit se te redirige a esta sección.
    • Están afectados Safari (macOS) y todos los navegadores de iPhone y iPad, incluidos Chrome, Firefox y Edge para iOS/iPadOS, porque Apple obliga a usar WebKit en esos sistemas.
    • En Linux y Windows funciona con Firefox o con navegadores basados en Chromium (Chrome, Edge, Brave…). En macOS debería funcionar igual, pero no se ha probado.
