Protocolo MCP (Model Context Protocol)

Conecta ZeroChat con tus herramientas externas, bases de datos o servicios del sistema operativo mediante el estándar abierto MCP.

Las herramientas locales usan zmcp_<herramienta> y las externas mcp_<servicio>_<herramienta>, por ejemplo mcp_browser_service_browser_navigate. Los permisos se guardan por este nombre completo: autorizar una herramienta no autoriza su homónima en otro servicio. No se admiten alias antiguos. Los caracteres especiales se codifican para evitar colisiones.

1. ¿Qué es MCP?

El Model Context Protocol (MCP) es un estándar abierto promovido por Anthropic para conectar modelos de inteligencia artificial con fuentes de datos y herramientas del mundo real de manera uniforme.

ZeroChat implementa un cliente MCP completo sobre SSE (Server-Sent Events) y HTTP. Esto te permite conectar el navegador con cualquier servidor MCP que ejecutes en tu máquina (por ejemplo, en Python, Node.js o Go) para dar al modelo acceso a bases de datos SQL, sistemas de archivos, APIs internas de tu empresa o utilidades de línea de comandos.

2. Conexión y Estado en la Interfaz

En la barra inferior del composer encontrarás el botón con icono de enchufe para MCP:

  • Borde neutro / desconectado: No hay ningún servidor MCP activo.
  • Borde verde / conectado: ZeroChat ha establecido conexión con el servidor y ha descubierto sus herramientas.

Al hacer clic en el botón MCP se abre el modal de configuración, donde puedes especificar el host y el puerto de tu servidor local (por defecto http://127.0.0.1:6388/sse) y pulsar "Conectar". Para evitar avisos innecesarios de acceso a red local en el navegador al abrir la app por primera vez, la conexión automática solo se producirá tras haber conectado o configurado MCP al menos una vez en ese equipo.

3. Servidor Local en Python (Zero Dependencias y Gestor Stdio)

Para que no tengas que escribir un servidor desde cero, ZeroChat incluye en el propio diálogo de configuración un generador automático de código Python para el servidor local (zmcp.py).

Este servidor cumple un doble rol transparente:

  1. Herramientas Locales Esenciales (Core): Implementadas directamente con la librería estándar de Python 3, sin requerir dependencias externas ni entornos virtuales:
    • execute_command: Terminal shell unificado para Git, CLI, pruebas y compilación, enriquecido con diagnóstico del sistema operativo.
    • read_file: Lectura segura de archivos con rangos de líneas y límites de contexto.
    • edit_file: Creación y edición atómica de archivos (sobrescritura, anexado o reemplazo de bloques).
    • list_directory: Exploración estructurada de carpetas y metadatos de archivos.
  2. Gestor de Servidores MCP Externos (stdio): Permite arrancar y consumir servidores MCP de la comunidad que se comunican por entrada/salida estándar (stdio JSON-RPC 2.0). Cada servicio publicado declara su propio instalador y comando de arranque, y puede iniciarse o detenerse desde la interfaz.

Los servicios se organizan de forma independiente, uno por directorio. El catálogo distribuido incluye el servicio de prueba dummy_mcp y Playwright MCP para automatización de navegador; ambos permanecen desactivados hasta que decidas iniciarlos.

# Arrancar el servidor local en Python para ZeroChat (puerto 6388 por defecto)
python3 zmcp.py

4. Control de Permisos y Autorización por Herramienta

Dado que las herramientas MCP externas pueden ejecutar acciones sensibles en tu máquina (como modificar archivos o consultar bases de datos), ZeroChat incorpora un panel de control granular para cada herramienta descubierta:

Abre Ajustes → Permisos para elegir la política global, revisar los permisos recordados y restablecerlos cuando sea necesario. La configuración del servidor MCP se mantiene separada en la pestaña MCP.

Al pulsar Arrancar servicios MCP externos, la preparación se ejecuta en segundo plano. Una única línea bajo el botón muestra su estado hasta que los servicios estén preparados o se produzca un error. Cada servicio externo puede incluir opciones declarativas de configuración (como conmutar la navegación visible o en segundo plano en Playwright), ajustables directamente desde la interfaz.

  • Interruptor On/Off: Permite activar o desactivar individualmente cada herramienta expuesta por el servidor MCP sin necesidad de reiniciar el servicio.
  • Política de autorización:
    • Automático: El agente puede ejecutar la herramienta de forma transparente.
    • Pedir confirmación: ZeroChat pausará la ejecución y solicitará tu aprobación explícita mediante un diálogo modal antes de permitir la invocación.
Seguridad en red local: Asegúrate de que tu servidor MCP escuche únicamente en la interfaz local 127.0.0.1 y no en 0.0.0.0 si estás conectado a una red pública no confiable.
