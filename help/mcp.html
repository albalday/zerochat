Protocolo MCP (Model Context Protocol)

Conecta ZeroChat con tus herramientas externas, bases de datos o servicios del sistema operativo mediante el estándar abierto MCP.

1. ¿Qué es MCP?

El Model Context Protocol (MCP) es un estándar abierto promovido por Anthropic para conectar modelos de inteligencia artificial con fuentes de datos y herramientas del mundo real de manera uniforme.

ZeroChat implementa un cliente MCP completo sobre SSE (Server-Sent Events) y HTTP. Esto te permite conectar el navegador con cualquier servidor MCP que ejecutes en tu máquina (por ejemplo, en Python, Node.js o Go) para dar al modelo acceso a bases de datos SQL, sistemas de archivos, APIs internas de tu empresa o utilidades de línea de comandos.

2. Conexión y Estado en la Interfaz

En la barra inferior del composer encontrarás el botón indicador de MCP:

  • Punto gris / desconectado: No hay ningún servidor MCP activo.
  • Punto verde / conectado: ZeroChat ha establecido conexión con el servidor y ha descubierto sus herramientas.

Al hacer clic en el botón MCP se abre el modal de configuración, donde puedes especificar el host y el puerto de tu servidor local (por defecto http://127.0.0.1:8000/sse) y pulsar "Conectar".

3. Generador de Servidor FastMCP Integrado

Para que no tengas que escribir un servidor desde cero, ZeroChat incluye en el propio diálogo de configuración un generador automático de código Python FastMCP.

Selecciona tu sistema operativo (Linux, macOS o Windows) y verás:

  1. El comando para instalar FastMCP con pip o uv.
  2. El script completo en Python con funciones de ejemplo listas para usar (como consultas meteorológicas, cálculos o utilidades).
  3. El comando exacto para arrancar el servidor en terminal con soporte de CORS activado.
# Arrancar un servidor FastMCP en Python para ZeroChat
uv run fastmcp run server.py --transport sse --port 8000

4. Control de Permisos y Autorización por Herramienta

Dado que las herramientas MCP externas pueden ejecutar acciones sensibles en tu máquina (como modificar archivos o consultar bases de datos), ZeroChat incorpora un panel de control granular para cada herramienta descubierta:

  • Interruptor On/Off: Permite activar o desactivar individualmente cada herramienta expuesta por el servidor MCP sin necesidad de reiniciar el servicio.
  • Política de autorización:
    • Automático: El agente puede ejecutar la herramienta de forma transparente.
    • Pedir confirmación: ZeroChat pausará la ejecución y solicitará tu aprobación explícita mediante un diálogo modal antes de permitir la invocación.
Seguridad en red local: Asegúrate de que tu servidor MCP escuche únicamente en la interfaz local 127.0.0.1 y no en 0.0.0.0 si estás conectado a una red pública no confiable.
