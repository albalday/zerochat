Protocolo MCP (Model Context Protocol)

Usa herramientas de tu equipo y servicios MCP externos desde ZeroChat, con el servidor local y controles de autorización integrados.

Las herramientas locales usan zmcp_<herramienta> y las externas mcp_<servicio>_<herramienta>, por ejemplo mcp_browser_service_browser_navigate. Los permisos se guardan por este nombre completo: autorizar una herramienta no autoriza su homónima en otro servicio. No se admiten alias antiguos. Los caracteres especiales se codifican para evitar colisiones.

1. ¿Qué es MCP?

El Model Context Protocol (MCP) es un estándar abierto promovido por Anthropic para conectar modelos de inteligencia artificial con fuentes de datos y herramientas del mundo real de manera uniforme.

En ZeroChat, el servidor local inicia en 127.0.0.1, abre la aplicación con un token de sesión y el navegador se conecta automáticamente. Puedes instalarlo desde PyPI o ejecutar el archivo zerochat.py directamente. No se configura manualmente una URL MCP remota.

2. Conexión y Estado en la Interfaz

Abre Ajustes → MCP para consultar el estado del servidor local y las herramientas detectadas:

  • Desconectado: El servidor local no está disponible. Deja zerochat o zerochat.py ejecutándose y recarga la página si se ha reiniciado.
  • Conectado: ZeroChat ha descubierto las herramientas locales y puede mostrar los servicios MCP externos disponibles.

No hay botón ni formulario de conexión manual. Ejecuta el comando siguiente y abre la aplicación desde el enlace que inicia el script. El token de sesión protege las peticiones al servidor local: no compartas esa URL ni el token.

3. Servidor Local: PyPI o zerochat.py

La forma recomendada es instalar el paquete oficial desde PyPI. Incluye el servidor local y una copia local de la interfaz web.

También puedes descargar zerochat.py y ejecutarlo directamente. Ambas opciones arrancan el servidor SSE y abren el navegador con un token efímero de sesión.

Herramientas Locales Esenciales:

  • execute_command: Terminal shell unificado para Git, CLI, pruebas y compilación, enriquecido con diagnóstico del sistema operativo.
  • read_file: Lectura segura de archivos con rangos de líneas y límites de contexto.
  • edit_file: Creación y edición atómica de archivos (sobrescritura, anexado o reemplazo de bloques).
  • list_directory: Exploración estructurada de carpetas y metadatos de archivos.

Seguridad por Token: Todas las peticiones desde zerochat.html requieren el token efímero de sesión generado al arrancar. Sin este token, el servidor local rechaza cualquier conexión externa. 

# Recomendado: instalar el paquete oficial de PyPI
pip install zerochat && zerochat

# Alternativa: descargar y ejecutar el script directamente
curl -sL https://albalday.github.io/zerochat/zerochat.py -o zerochat.py && python3 zerochat.py

4. Control de Permisos y Autorización por Herramienta

Dado que las herramientas locales pueden ejecutar acciones sensibles en tu máquina (como modificar archivos o ejecutar comandos), ZeroChat incorpora un panel de control granular para cada herramienta:

Abre Ajustes → Permisos para elegir la política global, revisar las decisiones recordadas y restablecerlas cuando sea necesario. Desde el panel MCP también puedes elegir Preguntar, Permitir o Denegar para cada herramienta.

  • Interruptor On/Off: Permite activar o desactivar individualmente cada herramienta expuesta al modelo sin detener el servidor.
  • Política de autorización:
    • Pedir autorización (recomendado): ZeroChat pausa la ejecución para solicitar tu aprobación explícita.
    • Todo autorizado: Cualquier herramienta se ejecuta sin confirmaciones. Úsalo solo en un entorno de confianza.
Seguridad en red local: Asegúrate de que tu servidor MCP escuche únicamente en la interfaz local 127.0.0.1 y no en 0.0.0.0 si estás conectado a una red pública no confiable.

5. Servicios MCP Externos y Activación Individual

El servidor local zerochat.py gestiona los servicios MCP externos definidos en services/. No necesitas ejecutar un daemon externo global: cada servicio se inicia y se detiene desde ZeroChat.

En Ajustes → MCP, "Servidores MCP Disponibles" permite iniciar o detener cada servicio y configurar sus opciones. Al iniciarlo, ZeroChat instala las dependencias necesarias cuando corresponda, descubre sus herramientas y las añade al panel. Los servicios basados en Node.js requieren Node.js 18 o posterior y npm.

El servidor local incluye definiciones listas para usar en services/:

  • dummy_mcp: Servicio mínimo de prueba en Python puro sin dependencias.
  • playwright: Automatización de navegador con Playwright MCP oficial; la opción Headless controla si se muestra la ventana.
  • memory: Grafo de conocimiento y memoria persistente estructurada.
  • lsp: Language Server Protocol para navegación de código e inteligencia de tipos.
