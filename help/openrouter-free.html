Obtener una API key de OpenRouter

Crea una clave de OpenRouter para usarla en ZeroChat.

Pasos

  1. Abre la página oficial de API keys de OpenRouter e inicia sesión o crea una cuenta.
  2. Pulsa Create API Key o Create Key.
  3. Escribe un nombre reconocible, por ejemplo ZeroChat, y crea la clave.
  4. Copia la clave inmediatamente y guárdala en un lugar privado. OpenRouter solo muestra el valor completo una vez.
  5. En ZeroChat, crea o edita un perfil de proveedor OpenRouter, pega la clave y selecciona un modelo.

Importante

Los modelos, límites y precios cambian. Consulta siempre el catálogo y las condiciones actuales de OpenRouter antes de usarlo en producción.

No compartas la API key ni la publiques en chats, capturas de pantalla, repositorios o archivos de configuración públicos.
