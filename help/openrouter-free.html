Obtener una API key gratuita de OpenRouter

Solo necesitas una cuenta de OpenRouter. No hace falta añadir crédito para probar sus modelos gratuitos.

Pasos

  1. Abre la página oficial de API keys de OpenRouter e inicia sesión o crea una cuenta.
  2. Pulsa Create API Key o Create Key.
  3. Escribe un nombre reconocible, por ejemplo ZeroChat, y crea la clave.
  4. Copia la clave inmediatamente y guárdala en un lugar privado. OpenRouter solo muestra el valor completo una vez.
  5. En ZeroChat, crea o edita un perfil de proveedor OpenRouter, pega la clave y selecciona un modelo gratuito.

Importante

El nivel gratuito sirve solo para pruebas breves. Ofrece modelos gratuitos menos potentes, con límites bajos y capacidad compartida; la respuesta puede degradarse o no estar disponible cuando hay mucha carga.

No es una opción adecuada para conversaciones largas, tareas exigentes ni uso en producción. Los límites y los modelos disponibles pueden cambiar; consulta siempre el catálogo y las condiciones actuales en OpenRouter.

No compartas la API key ni la publiques en chats, capturas de pantalla, repositorios o archivos de configuración públicos.
