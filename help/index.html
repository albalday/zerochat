¿Qué es ZeroChat?

ZeroChat es un cliente web autónomo, seguro y portátil para interactuar con modelos de inteligencia artificial, orquestar agentes autónomos y consultar bases de conocimiento documental locales.

A diferencia de las plataformas habituales, ZeroChat se distribuye en un único archivo HTML (zerochat.html) que funciona directamente desde el protocolo file:// o cualquier servidor estático sin dependencias, bases de datos remotas ni intermediarios. Toda la información personal, conversaciones, configuraciones y documentos indexados permanecen estrictamente bajo tu control dentro de tu propio navegador.

Privacidad por diseño: ZeroChat no recopila telemetría ni envía datos a servidores propios. Tus peticiones viajan directamente desde tu navegador al proveedor que configures o se ejecutan de forma local en tu hardware mediante WebGPU.
