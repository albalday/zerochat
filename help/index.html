¿Qué es ZeroChat?

ZeroChat es un cliente web autónomo, seguro y portátil para interactuar con modelos de inteligencia artificial, orquestar agentes autónomos y consultar bases de conocimiento documental locales.

A diferencia de las plataformas habituales, ZeroChat se sirve como una aplicación web estática (zerochat.html) que funciona directamente en GitHub Pages o en cualquier servidor estático sin dependencias pesadas, bases de datos remotas ni intermediarios. Toda la información personal, conversaciones, configuraciones y documentos indexados permanecen estrictamente bajo tu control dentro de tu propio navegador.

Abrir ZeroChat (zerochat.html) Listo para usar directamente en el navegador o conectar con tu backend local en zerochat.py.

Dos formas de arranque: Web autónoma vs. Backend local

  • zerochat.html (Web directa / PWA): Abre directamente en cualquier navegador o dispositivo móvil (especialmente optimizado para Android como PWA). Por defecto usa modo oscuro y, en móvil, mantiene cerrado el panel de conversaciones para priorizar el chat; ambos se pueden cambiar desde los controles de la interfaz. Ofrece inferencia comercial o local (WebLLM/WebGPU), base documental RAG en navegador (Orama), modo Agente con sandbox JS y persistencia en IndexedDB sin requerir Python, terminal ni instalación.
  • zerochat.py (Local con backend Python): Servidor local en segundo plano (puerto 6388 con token efímero seguro). Añade sobre la versión web el control del sistema operativo anfitrión: lectura y edición de archivos locales en disco, comandos de terminal y servidores MCP externos (Playwright, LSP, memoria).
