¿Qué es ZeroChat?

ZeroChat es un cliente web de uso personal para conversar con modelos de IA, consultar documentos y probar herramientas. La serie 8.x consolida las funciones existentes; el desarrollo de nuevas funcionalidades queda en pausa por el momento.

El historial se guarda en el navegador. Los mensajes, adjuntos y resultados que forman parte de una petición se envían al proveedor seleccionado. Las herramientas web pueden usar servicios intermediarios. No hay sincronización automática entre dispositivos ni una garantía de privacidad absoluta.

Abrir ZeroChat (zerochat.html) Listo para usar directamente en el navegador o conectar con tu backend local en zerochat.py.

Dos formas de arranque

  • Web: abre ZeroChat por HTTPS y configura un perfil. Permite chat, adjuntos, RAG y herramientas del navegador sin Python. WebLLM requiere WebGPU. La instalación PWA, si se admite, se hace desde el navegador; ZeroChat no muestra avisos de instalación.
  • Servidor local: inicia zerochat o zerochat.py para añadir archivos, comandos y servicios MCP. Revisa los permisos antes de habilitar herramientas.

Servidor local: instalación recomendada

Instala el ejecutable oficial desde PyPI; abre la interfaz de GitHub Pages con una sesión autenticada con el servidor local. PyPI y la descarga directa usan el mismo directorio ~/zerochat/ para el estado y los MCP.

pip install zerochat && zerochat

Alternativa directa: descarga zerochat.py y ejecútalo con Python.

Descargar zerochat.py: zerochat.py

Ejecutar directamente (curl): 

curl -sL https://albalday.github.io/zerochat/zerochat.py -o zerochat.py && python3 zerochat.py

Puedes borrar ~/zerochat/ para eliminar configuración, token, servicios MCP y sus dependencias, sin borrar el ejecutable instalado o descargado.
