Obtener una API key de Gemini

La clave se crea desde Google AI Studio con tu cuenta de Google.

Pasos

  1. Abre la página oficial de API keys de Google AI Studio e inicia sesión con tu cuenta de Google.
  2. Acepta las condiciones si Google te las solicita. Las cuentas nuevas pueden recibir un proyecto y una clave inicial automáticamente.
  3. Si no tienes una clave para usar, pulsa Create API key y sigue el diálogo para crear o elegir un proyecto.
  4. Copia la API key y guárdala en un lugar privado.
  5. En ZeroChat, crea o edita un perfil de proveedor Gemini, pega la clave y selecciona un modelo disponible.

Importante

Los modelos, límites, precios y disponibilidad cambian. Consulta la información oficial de Gemini API antes de usarla en producción.

No compartas la API key ni la publiques en chats, capturas de pantalla, repositorios o archivos de configuración públicos.
