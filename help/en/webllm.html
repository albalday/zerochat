WebLLM & WebGPU Configuration

Step-by-step setup guide for running AI models directly on your hardware GPU inside the browser.

What is WebLLM and what are its advantages?

WebLLM is a cutting-edge engine that executes Large Language Models entirely inside the web browser utilizing your graphics card (GPU) through the standardized WebGPU API.

  • Complete privacy: Prompts and responses never leave your device; there is zero telemetry or intermediary servers.
  • Zero cost or subscription: Requires no paid API keys or cloud server infrastructure.
  • Offline functionality: Once a model is downloaded into your browser's persistent Cache Storage, it runs even without internet access.

Hardware Requirements & VRAM Guidelines

WebGPU performance depends on available GPU video memory (VRAM):

Model Parameter Size Recommended VRAM Sample Models in Catalog
0.5B – 1.5B (Lightweight) 1.5 GB – 2.5 GB Qwen2.5-0.5B, SmolLM2-1.7B, Qwen2.5-1.5B
3B – 4B (Balanced) 3 GB – 4.5 GB Llama-3.2-3B, Phi-3.5-mini

Browser Configuration: WebGPU Setup

Chromium / Chrome / Edge / Brave

  1. Enable hardware acceleration in browser settings.
  2. Enable unsafe WebGPU flag if your platform requires it: 
    chrome://flags/#enable-unsafe-webgpu
  3. Restart your browser to apply changes.

Mozilla Firefox

  1. Open a new tab and navigate to about:config.
  2. Search for and set the following flag to true: 
    dom.webgpu.enabled = true
  3. Verify WebGPU status under about:support.

How to Use WebLLM in ZeroChat

  1. Open the Profile Management dialog in ZeroChat.
  2. Select the WebLLM (local WebGPU) interface type.
  3. If you already have downloaded models: They appear automatically at the top of the model selection combo. Pick any downloaded model and save immediately without querying.
  4. To download a new model: Click Query. Browse the catalog with required VRAM metrics, click the download icon next to your desired model, and wait for shader compilation to finish.

Troubleshooting Common Issues

  • "WebGPU is not available in this browser": Ensure you are running the latest browser version with WebGPU flags enabled as described above.
  • Out of Memory (OOM) Errors: If the tab crashes or reloads during shader compilation, select a lighter model (0.5B – 1.5B) or close other GPU-intensive tabs.
  • Private Browsing / Incognito Mode: Incognito mode may wipe browser cache on exit. Use a regular browsing window to keep downloaded models permanently cached.
