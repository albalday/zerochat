Get an OpenRouter API key

ZeroChat 8.x · Configuring a OpenRouter key in a ZeroChat profile.

Steps

  1. Open the OpenRouter key page and sign in to your account.
  2. Create a key using your account's options and keep it private. Gemini may require creating or selecting a project.
  3. In ZeroChat, create or edit a OpenRouter profile, enter the key and press Query.
  4. Select an available model and save the profile. Try a short message first.

If you cannot create a key or the query fails, check account permissions and the official OpenRouter guide. Interface labels and options may change.

Usage and limits

Creating a key does not guarantee free usage. Models, quotas, pricing, availability and data handling depend on the provider and account. Check their terms before sending personal data or enabling billing.

ZeroChat uses the key from your browser for provider requests. Do not publish it or share profile backups without reviewing their content and protection. If exposed, revoke it at the provider and configure a new one.
