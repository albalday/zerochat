Get a free OpenRouter API key

You only need an OpenRouter account. You do not need to add credit to try its free models.

Steps

  1. Open OpenRouter’s official API keys page and sign in or create an account.
  2. Select Create API Key or Create Key.
  3. Enter a recognizable name, such as ZeroChat, and create the key.
  4. Copy the key immediately and store it privately. OpenRouter shows its complete value only once.
  5. In ZeroChat, create or edit an OpenRouter provider profile, paste the key, and choose a free model.

Important

The free tier is only for brief tests. It offers less capable free models, with low limits and shared capacity; responses may slow down or become unavailable when demand is high.

It is not suitable for long conversations, demanding tasks, or production use. Usage limits and available models may change, so always check OpenRouter for the current catalog and terms.

Never share the API key or publish it in chats, screenshots, repositories, or public configuration files.
