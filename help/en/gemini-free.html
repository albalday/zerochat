Get a free Gemini API key

Create the key in Google AI Studio using your Google account.

Steps

  1. Open Google AI Studio’s official API keys page and sign in with your Google account.
  2. Accept the terms if Google asks you to. New accounts may receive an initial project and API key automatically.
  3. If you do not have a key to use, select Create API key and follow the dialog to create or choose a project.
  4. Copy the API key and store it privately.
  5. In ZeroChat, create or edit a Gemini provider profile, paste the key, and select a model available in the free tier.

Important

The free tier is only for brief tests. It provides less capable free models and limited quotas with shared capacity; responses may slow down or become unavailable when demand is high.

It is not suitable for long conversations, demanding tasks, or production use. You do not need to set up billing to try that tier.

Quotas, models, and regional availability can change. Check Gemini API’s official billing and tiers information when you need to confirm them.

Never share the API key or publish it in chats, screenshots, repositories, or public configuration files.
