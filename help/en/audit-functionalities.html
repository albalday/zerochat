Review 2: Features

ZeroChat 9.1.0 as the single frontend for local models. Updated on 13 October 2026 after checking against a local server.

1. Goal and method

The project's current goal is to use ZeroChat as the single frontend for local models, served through an OpenAI-compatible API (vLLM, SGLang, llama.cpp or LM Studio) or Ollama. The model changes with the task, so the review does not depend on any particular one and proposes no model-specific changes. It checks what version 9.1.0 (commit a0393c3) offers for that use and for remaining a personal lab for agents, tools and MCP.

Following the 9.0.0 lesson, each capability states what protects it: [test] an automated test, [reading] code review without a test. The first version was not tried against a real server. On 13 October it was checked against a local llama.cpp server running a reasoning and vision model (section 3).

4. Consistency with the help

The help was checked against the code on the points that changed since 8.12.4:

  • Tools and agent: eleven built-in tools, agent with no step limit, loop detection after 5 repetitions and read-only subagents. Matches.
  • Local server and MCP: file tools, run_command with a 30 s default and 10 minute maximum, check_command and permission policies. Matches.
  • Reasoning and telemetry: the 60, 70 and 85 % thresholds and reasoning replay. Matches.
  • Mismatches fixed in this review: the help and README.md still referred to the "8.x" series; README.md mentioned "plans and checkpoints", tools that no longer exist; and the previous audit described a loop of 5 to 200 turns with agent_checkpoint, update_plan and finish_task, removed before 9.0.0.

At review time no test watched this consistency. Since R-09 was closed (Review 1), test_help_pages.js checks each page's translation, links and series. Whether the text matches the behaviour still depends on each change updating its page.

5. Limits

  • Single user: no concurrent sessions or roles.
  • Data in the browser: clearing site data without exporting loses it.
  • Shared origin on GitHub Pages (accepted risk).
  • Lexical RAG: no semantic search.
  • Browsers: Chromium and Firefox; WebKit (Safari and all iPhone/iPad browsers) not supported.
  • Privacy: with a local LLM messages do not leave the computer, but web tools still use third-party services.

6. Verdict

Suitable as the single frontend for local models, on one condition: the server must separate reasoning and tool calls into their own fields and publish its context capacity (F-02 to F-04). These are server settings, not ZeroChat changes, and the debug panel lets you check them.

After closure: with llama.cpp all three conditions hold with no extra configuration. F-01 was solved with a change that works for any model, F-05 was dropped and the help consistency test exists since R-09.
