Infrastructure and data

How features are divided between the browser and the local server.

Choose your usage mode

The web app runs in your browser. The optional Python server adds tools from your computer; it does not replace the interface.

If supported, install the web app as a PWA from your browser's options. Cached resources do not guarantee that every feature works offline.

Where data is stored

In the browser

Conversations, profiles, attachments and RAG stay in browser storage. They belong to the web address, browser and profile used; there is no automatic cross-device sync. Export copies before clearing data.

Conversations are not encrypted as a vault. See Profiles for API key encryption and its limits.

On your computer, with the local server

~/zerochat/
├── config/      Token and configuration
├── services/    MCP definitions, dependencies and credentials
└── .venv/       Python MCP dependencies

PyPI and the downloaded script use the same folder. Deleting it removes local configuration and managed services, including their credentials. It does not remove the executable, browser history or files changed outside that folder.

Connections and privacy

The published interface is GitHub Pages. The local server listens at 127.0.0.1:6388 by default and opens an authenticated link. Do not share the startup URL while it contains the token; the interface removes it and stores it in a cookie.

Remote providers receive messages, attachments and tool results included in their requests. Web tools may use intermediaries such as Jina Reader or AllOrigins. Models and dependencies also require downloads.

WebLLM runs inference locally; network tools still send data. Local history does not make all operations private. The debug panel shows requests; their context may differ from visible history because of token limits or RAG selection.

Updates

Web updates arrive from GitHub Pages. Patches in the same series, such as 8.5.x, are compatible with backend 8.5 and do not require reinstalling it.

A new major.minor series may require a backend update. Follow the terminal notice for your installation method; the executable does not update automatically. Press i when the terminal offers information.

Local development and technical reports

Inside the repository, python3 zerochat.py serves http://127.0.0.1:6388/zerochat.html. Its browser storage is separate from GitHub Pages. The interface loads js/ and css/; copying the HTML alone is not enough.

python3 zerochat.py --test checks local tools. For the project test suite, see tests/README.md in the repository.
