Reasoning (Thinking) & Telemetry

Reasoning settings and interpretation of context metrics.

1. Model reasoning

Some providers return reasoning content or a summary that ZeroChat displays in a collapsible block. This is what the API exposes, not a complete view of the model's internal process.

The composer's reasoning control lets you choose from None to Maximum. ZeroChat maps the level to parameters supported by each adapter. None omits explicit configuration: it does not guarantee disabling reasoning used by a model by default. Availability and effect depend on the model.

The same menu can enable agent_checkpoint so the agent records findings and next steps. This tool is separate from native reasoning; it does not verify the answer.

2. Context indicator

The indicator, for example ~1.4k / 128k*, compares used tokens with the known or assumed capacity. ~ marks estimated usage and * marks assumed capacity.

  • Normal: below 60%.
  • Warning: from 60% to below 85%.
  • Critical: 85% and above.

These are UI guidance thresholds. Context includes instructions, history, tools and results, not just the last message. If it grows too large, reduce attachments or start a conversation with a checked summary. Branching while retaining all history does not free that context.

When the history reaches 70% of the input budget, ZeroChat automatically compacts it into a summary before the next request and shows the line “Compacting context.....” in the chat. The model itself writes the summary, which may leave out details.

3. Telemetry details

Context window

Click the indicator to see usage, capacity and available space. Provider data is used when available, with estimates otherwise. Manually setting capacity changes ZeroChat's reference; it does not enlarge the server's actual window. Sent context may exclude older messages to fit the budget even while they remain visible in history.

Cache

Cache read and write tokens appear when reported by the provider. They do not measure financial savings: rates and conditions depend on the service.

Last turn

The panel displays input and output tokens, generation speed and time to first token when data is available. Metrics may be missing or vary between providers; they are neither an invoice nor a controlled performance comparison.
