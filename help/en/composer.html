Composer, Shortcuts & Attachments

Compose prompts comfortably, use keyboard shortcuts, and attach multi-format files and source code.

1. The Floating Composer

ZeroChat's input area is built for a responsive, fluid typing experience:

  • Smooth Auto-expansion: The input box grows as you type longer prompts (using field-sizing: content with fallback) without overflowing the viewport.
  • Integrated Controls Bar: Groups attachment upload, thinking controls, agent tools, MCP status, RAG knowledge, telemetry, and active profile selection.
  • Stop Stream Button: During real-time token generation, the send button switches to an instant stop control.

2. Essential Keyboard Shortcuts

Shortcut Context Action Performed
Enter In prompt textarea Send message to model.
Shift + Enter In prompt textarea Insert a new line without sending.
Escape In any open modal or menu Close active popup or dialog.
Arrow Keys ↑ / ↓ In profile selection menu Navigate through available profiles.
Ctrl / Cmd + V Anywhere in chat window Paste images or text directly from clipboard.

3. Attaching Files & Documents

ZeroChat includes a client-side file ingestion engine (file-parser.js). Attach files via the paperclip icon or by dragging and dropping them into the window.

Supported Formats:

  • Images (PNG, JPEG, WebP, GIF): For vision-capable models (e.g., GPT-4o, Claude 3.5/3.7, Gemini Flash/Pro).
  • PDF Documents: Text is extracted client-side with page count and title metadata.
  • Source Code & Scripts: .js, .ts, .py, .html, .css, .json, .sql, .c, .rs, .go, .sh with syntax highlighting.
  • Data Tables: .csv and .tsv files for data extraction and charting.
  • Text Files: .md, .txt, .xml, .yaml.
Preview & Removal: Miniatures show file name and size before sending. Click the "X" on any item to discard it.

4. Rich Message Formatting

Assistant responses are rendered with a high-performance Markdown engine featuring:

  • Syntax-highlighted code blocks with a quick copy button.
  • Formatted tables with alignment styling.
  • LaTeX math equations (KaTeX) inline and in block mode.
  • Collapsible Thinking blocks with deliberation timers.
  • Interactive Tool Cards for agent executions.
