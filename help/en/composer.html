Composer, Shortcuts & Attachments

Writing messages, attaching files and reviewing what is sent to the provider.

1. Message input

The field grows as you type. Its lower bar contains attachments, reasoning, RAG selection and context; tools and MCP are configured in Settings.

Press Send to start a response. During generation, the button lets you stop it. Stop requests cancellation: it does not undo an edit, command or web action that has already run.

2. Keyboard shortcuts

  • Enter: send the message from the text field.
  • Shift + Enter: insert a line break.
  • Escape: close dialogs or menus that support this shortcut.
  • ↑ / ↓: move through profile selector options.
  • Ctrl / Cmd + V: paste text; image pasting depends on clipboard content and permissions.

3. Attachments

Use the paperclip, drag files into the chat or paste an image. Review attachments before sending and remove unwanted ones with their close button.

  • Images: require a vision model; accepting a file locally does not ensure the provider accepts its format or size.
  • PDF: text is extracted in the browser. Scans without text and complex layouts may produce incomplete results; there is no general OCR.
  • Text and code: supported formats include TXT, Markdown, JSON, JavaScript, Python, HTML and CSS.
  • CSV and TSV: sent as text for the model to analyse; check delimiters, units and results.

Attachment content is sent to the provider with the message and consumes context. To consult parts of several documents, use the RAG collection.

4. Message presentation

Responses support Markdown, tables, code blocks with copy controls and KaTeX formulas. Reasoning exposed by the provider appears in collapsible blocks; tool calls have cards showing arguments, results and status.

Formatting does not validate content: check code, calculations and links before using them.
