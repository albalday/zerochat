Audit 4: Evolution According to Git

772 commits in 40 days, from ChatCLI v0.9 to ZeroChat 8.12.4.

Method and limits

Facts are checked with git log and git show; dates and versions come from each commit. Interpretations are marked as such. Most commits only have a title: the history does not record the reasons for decisions, so this report does not attribute undocumented causes.

1. Figures for the period

  • 772 commits between August 26 and October 4, 2026: about 19 a day, peaking at 65 (Aug 29) and 74 (Sep 2).
  • Commits list several coding agents as co-authors (Claude Opus 5, Opus 5.5, Fable 5.1). From September 2 the documentation mentions "zero-code" development with Codex and Antigravity.
  • Interpretation: the pace fits development directed by instructions and carried out mostly by agents, as stated in Learning.

2. Phases

Multimedia ChatCLI (August 26–27)

Initial commit ChatCLI v0.9 (39fed30). v2.1 adds multi-chat, SVG charts, STT/TTS voice and export (dfdc964). The agent loop moves from recursion to a while loop (1fdf4d5). Avatars are removed (cd45cd8).

AgentCore and MCP (August 28–31)

The voice subsystem is removed (cbc4cb1). AgentCore and the first MCP support arrive (140d5a8, 969526e). A minifying bundler appears (f416f53). The project is renamed ZeroChat v5.1 with experimental Tree-RAG, which stored Markdown summaries on the file system (ad107f4, cdfb631, 6bc97d4).

Orama, rules and UI (September 2–16)

RAG with Orama and ZeroChatDB (481c9c6, v5.3.0) and the first AGENTS.md (d37ff35), both on Sep 2. SVG icons (abb692c, v6.0.0), injected messages in English (cfdab94, v6.5.2), internal dialogs (11a0389, v6.5.4) and WebLLM on Sep 11 (e20a70c, v6.6.0).

Unified backend, PyPI and signatures (September 17–30)

First daily token (5ac5cd4). Unified zerochat.py and the bundle removed in v7.0.0 (f58544f). PyPI preparation and unified MCP environment (9083f2b, c69c382). Modular py/ backend (b3db5f0, v7.8.1). HMAC signatures for tool calls (c51d0a8, Sep 27).

Hardening and closing 8.x (October 1–4)

On Oct 3: ChatState slices (2059455), token with 0600 permissions (c6fca95) and documented acceptance of the shared-origin risk (d4692e1). On Oct 4: text <tool_call> for WebLLM (e44dd02), dead-code cleanup (ffdbc6c) and the 8.12.4 release (aff1019).

4. What the history adds

  • The current scope results from removals: voice, avatars, the bundle and Tree-RAG were dropped. The history records what was removed, not why.
  • Lexical RAG replaced Tree-RAG after about three days. There is no evidence that embeddings were tried.
  • AGENTS.md rules arrive together with their changes (icons, English, dialogs). Interpretation: the rulebook locks in decisions so agents do not revert them; commits do not document specific incidents.
  • <tool_call> is recent: it arrived more than three weeks after WebLLM and has little usage yet.
  • Backend security was hardened in the second half of the period: daily token, HMAC, 0600 permissions and accepted origin risk.
  • The pace calls for verification: the drafts of these audits contained date and capability errors.

Conclusion: the final state described in the other audits is real. The history explains how it was reached and reminds us that its most recent parts are the least proven by use.
