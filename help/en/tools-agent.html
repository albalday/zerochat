Agent Mode & Built-in Tools

Turn passive language models into active agents capable of reasoning, running code, querying the web, and rendering graphics.

1. What is Agent Mode in ZeroChat?

Agent Mode transforms the standard question-answer conversation into an autonomous, multi-turn reasoning loop (Agentic Loop).

When you submit a complex task, the model determines which tools it needs, issues structured function calls, ZeroChat runs the tool in your browser, and feeds the result back to the model until the goal is accomplished.

Max Turn Safety Limit (maxAgentTurns): You can configure the maximum consecutive turns an agent can run (typically 5 to 10), preventing runaway loops and token waste.

3. JavaScript Execution Under Technical Supervision

execute_javascript is a supporting tool for calculations, data processing, and algorithms. It is intended for use with the awareness and active supervision of a technical user, who can enable or disable it in Settings.

  • Web Worker execution: It normally runs in a separate thread to keep the interface responsive during calculations or heavier algorithms.
  • Time limit: If a script exceeds the configured time, ZeroChat stops the Worker.
  • Output limits: Excessive results are truncated and console messages are limited to preserve responsiveness.
  • Restricted APIs for calculations: The Worker neutralizes network and sub-worker APIs that are unnecessary for this tool.

4. Interactive Tool Cards

When an agent calls a tool, ZeroChat renders a dedicated Tool Card directly in the chat message flow:

  • Live status indicator: Displays an animated spinner while processing and a green checkmark or error alert upon completion.
  • Collapsible input & output: Expand the card to inspect the exact arguments passed to the function and the data returned.
  • Full session persistence: Tool cards and their expanded/collapsed state are preserved across session reloads.
