Model Context Protocol (MCP)

Connect ZeroChat with your external tools, databases, or operating system utilities via the open MCP standard.

1. What is MCP?

The Model Context Protocol (MCP) is an open protocol championed by Anthropic to bridge AI models with external tools and databases through a standardized interface.

ZeroChat implements a full client MCP engine over SSE (Server-Sent Events) and HTTP. This lets your browser connect to any local or remote MCP server (written in Python, Node.js, Go, etc.) to give models access to local filesystems, SQL databases, internal company APIs, or CLI commands.

2. Connection & UI Indicators

In the composer bottom toolbar, locate the MCP status chip:

  • Grey indicator / Disconnected: No active MCP connection.
  • Green indicator / Connected: ZeroChat has connected to the server and discovered its exposed tools.

Click the MCP button to open the setup modal, configure your endpoint (default: http://127.0.0.1:6388/sse), and click "Connect".

3. Local Python Server (Zero Dependencies)

ZeroChat includes a one-click auto-generated Python local server script (zerochat_mcp.py) directly inside the configuration modal.

Unlike complex external frameworks, this server runs on the Python 3 standard library with zero external dependencies or virtual environments required for its core services:

  • execute_command: Unified shell terminal for Git, CLI, test execution, and compilation, with automatic OS and environment detection.
  • read_file: Safe file reading with line range slicing and context token limits.
  • search_files: Fast project file search by glob pattern and code text grep matching.
  • edit_file: Atomic file writing and editing (overwrite, append, or chunk replacement).
  • list_directory: Structured folder tree and metadata exploration.
  • browser_navigate: Web navigation and automation via Playwright (optional, installable via pip install playwright && playwright install chromium).
# Start the local Python server for ZeroChat (port 6388 by default)
python3 zerochat_mcp.py

4. Tool Permissions & Authorization Policies

Because external MCP tools can perform sensitive operations on your system, ZeroChat provides granular security controls for each tool:

  • On/Off Switches: Enable or disable individual tools without restarting the MCP server process.
  • Authorization Policy:
    • Automatic: The agent invokes the tool without user interruption.
    • Ask confirmation: ZeroChat halts execution and displays a modal prompt asking for explicit approval before running the tool.
Local network security: Make sure your MCP server binds strictly to the loopback interface 127.0.0.1 and not 0.0.0.0 when working on untrusted public networks.
