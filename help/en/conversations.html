Conversations, History & Branching

Local history, branches and conversation backups.

1. Sidebar and history

The sidebar lets you create, search by title, open, export and delete conversations. On mobile, open it from the top menu. History is grouped by date.

A new conversation keeps the selected profile. Messages are stored in the current browser and web origin; they do not automatically sync between devices or between GitHub Pages and localhost.

While a response is being generated, the view follows the end of the conversation. If you scroll up, it stops moving so you can read; it follows the end again when you scroll back down or send a message.

2. Conversation branches

The branch button on a response creates another conversation containing history up to that point. The original retains its later messages. You can continue both from the sidebar and try different questions or profiles.

Branching copies earlier context: it does not by itself shorten an oversized conversation. RAG branches are document collections and are managed separately.

3. Exporting conversations

  • JSON: an importable conversation copy, with messages and associated data included by the exporter.
  • Markdown: text to read or edit outside ZeroChat.
  • Print / PDF: opens a print view; the browser can save it as PDF.

A conversation export is not a full application backup: profiles have their own export, and RAG collections and downloaded models are not included. Review a file before sharing: it may contain messages, attachments and tool results.

4. Importing and keeping backups

Use Import conversation in the sidebar and select JSON exported by ZeroChat. The application validates its structure; it does not import PDF or Markdown as chat history. Import is blocked during generation.

Export conversations you want to keep before clearing browser data. Deleting a session or the entire history requires confirmation and has no recovery bin. Deleting ~/zerochat/ affects the local server, not browser chat history.
