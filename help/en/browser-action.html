Browser automation

Preparing and using browser_action with the local server.

browser_action is a local server tool that controls Chromium to navigate, take screenshots, click elements and fill forms. It requires Node.js, Playwright and a compatible browser. It does not control the ZeroChat tab or necessarily inherit sessions from your usual browser. Valid screenshots are shown in the tool card and sent to the model as visual evidence.

Setup

  1. Start the backend with zerochat or python3 zerochat.py and check that Node.js and npm are available to that process.
  2. To use the complete toolset, open Settings → MCP and start Playwright MCP. Its installation prepares Playwright and Chromium under ~/zerochat/services/playwright/.
  3. If browser_action is active, accept the replacement notice. ZeroChat disables it before starting Playwright MCP.

The local browser_action tool and external Playwright MCP tools are separate interfaces even when they share dependencies, but are offered as alternatives to avoid duplicate browser automation. A Node.js Playwright installation with Chrome, Edge or Chromium may also be detected. Installing the Python Playwright package does not satisfy this requirement.

If unavailable, check installation output and browser requirements for your system. Downloads may need network access and system libraries; installing the npm package alone does not guarantee Chromium will start.

Privacy and security: the tool can visit URLs and perform web actions requested by the model. Keep the permission policy set to “Ask” and review sensitive accounts or forms before automation.
