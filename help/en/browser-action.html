Browser automation

Minimum requirements for browser_action.

browser_action controls a headless Chromium browser to navigate, capture screenshots, click elements, and fill forms. It can only be enabled when Node.js, Playwright, and a compatible Chromium browser are available.

Recommended installation

  1. Install Node.js 18 or later, including npm.
  2. In ZeroChat, open Settings → MCP and start Playwright MCP. ZeroChat downloads Playwright and Chromium into ~/zerochat/services/playwright/.
  3. Reconnect the local server or reload ZeroChat. You can then enable browser_action.

You may alternatively use a Node.js-accessible Playwright installation with Google Chrome, Microsoft Edge, or Chromium. This tool does not need Python packages.

Privacy and security: the tool can visit URLs and perform web actions requested by the model. Keep the permission policy set to “Ask” and review sensitive accounts or forms before automation.
