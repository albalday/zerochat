Model browser

Choosing the browsing tool and the Playwright MCP browser in Settings › Browser.

In Settings › Browser you choose how the model browses. It needs the local server (zerochat) with Node.js and npm; on Windows, see Installing Node.js on Windows. Playwright cannot currently be used on Termux, so there is no model browser on Android. No option controls the ZeroChat tab.

  • None: the model does not drive a browser, although it can still search and read pages.
  • browser_action: a local server tool without options that opens pages, clicks, types and takes screenshots in a windowless Chromium. It uses the Playwright installed by the Playwright MCP service, so start that service once in Settings › MCP to install it. It only opens http:// and https:// addresses, including localhost and the local network to test sites in development, and never cloud metadata or link-local addresses.
  • Playwright MCP: the complete Playwright toolset, with the browser you choose below. When you save this option, Playwright MCP starts if it is stopped (and stops when switching to another option).

Only one of the two is offered to the model: even if Playwright MCP is running, its tools are not offered if you choose browser_action or none. The choice belongs to the active project’s environment (or general without a project), not the connection profile, and switching projects reconciles whether Playwright MCP starts or stops. Valid screenshots are shown in the tool card and handed to the model as visual evidence.

ZeroChat’s own browser

Playwright MCP opens a separate in-memory browser (--isolated), apart from yours: it keeps cookies and sessions while the session lasts, saves nothing to disk on close, and supports concurrent zerochat runs, including unattended runs without a graphical session.

  • Playwright engines and system browsers: Chromium, Firefox or WebKit (downloaded to the Playwright cache; Chromium is installed with the service, Install downloads the others showing progress, and Remove deletes them from the cache), or the browsers detected on the system (Google Chrome, Microsoft Edge or System Chromium) launched in an isolated ZeroChat profile without needing the extension: it is a new empty profile that does not see your cookies or sessions (to use them, choose Your browser).
  • User-Agent (only with Playwright’s Chromium, Firefox or WebKit; system Chrome, Edge and Chromium are real, up-to-date browsers and send their own): Automatic reuses the last real User-Agent captured from your browser and stored in SQLite (also in unattended runs), Rotate on each launch picks a different modern browser User-Agent on each session, and Custom uses the string you enter (up to 512 characters).
  • Show the window: by default the browser runs without a window (--headless); check it to watch what the model does.

Removing an engine stops Playwright MCP if it is running and starts it again when done.

Your browser

With this option, Playwright MCP connects to your Chrome, Edge or Chromium through the Playwright extension and uses your open tabs and sessions, without signing in again. You choose among the browsers detected on the system; it does not need to be the default one. Firefox and Safari do not support the extension; to use your Firefox sessions, sign in to those sites from the own browser.

  1. In the chosen browser, open the Playwright extension in the Chrome Web Store and click Add. In Edge, allow extensions from other stores first when asked. With Chromium, the profile where the extension is installed is used. Settings › Browser shows whether it is already installed in that browser.
  2. Keep that browser open. In Settings › Browser choose Your browser and the browser, and save.
  3. The first time the model browses after Playwright MCP starts, the extension asks you to accept the connection and choose the tab you share with it.

To avoid accepting every connection, click Save token… in Extension token and paste the token shown in the extension window; pasting the whole PLAYWRIGHT_MCP_EXTENSION_TOKEN=… line works. It is saved right away and never shown again (Settings only shows whether it is saved; Delete removes it). It is saved obfuscated in the local SQLite database (~/zerochat/storage/zerochat.db), readable only by your user, and Playwright MCP receives it via environment variable when it starts. Whoever has the token can connect to your browser without your approval: do not share it.

This mode always has a window: the model works in your open browser.

On save

With Save, the chosen tool is offered to the model in the active project, and the Playwright options are saved in SQLite and used the next time Playwright MCP starts; if it is running, ZeroChat asks whether to restart it now. Without the local server, the section only lets you choose the tool.

Privacy and security: the model can visit URLs and perform web actions. With Your browser it acts with your accounts: it can read what you see and submit forms on your behalf. Keep the permission policy on “Ask” and do not automate sensitive accounts or forms without reviewing them. In unattended runs the browser is not authorized on its own: without a saved authorization, the run pauses until you approve it.
