ZeroChat Help Center

Personal help for ZeroChat 8.x: usage, configuration and limits.

Start with the web app

ZeroChat lets you chat with AI models, consult documents and use tools. Open the app, create a connection profile and select a model.

Open ZeroChat (zerochat.html) No installation needed for web chat.

Chat, attachments and RAG work without Python. To access computer files, run commands or use MCP services, start the optional local server below. Usage modes, storage and privacy →

Add the local server

You need Python. Choose one of these alternatives; both open the web app and use ~/zerochat/ for local data.

Install from PyPI (recommended)

Linux, macOS and Android (Termux):

pip install zerochat
zerochat

Windows (PowerShell or CMD): use the py launcher, which works even if Python's Scripts folder is not on PATH.

py -m pip install zerochat
py -m zerochat

On subsequent launches, the second line is enough.

Download the script

curl https://albalday.github.io/zerochat/zerochat.py -o zerochat.py ; python3 zerochat.py

On subsequent launches, run python3 zerochat.py from the download folder. You can also download the file manually.

Keep the process running and use the link it opens. Then go to Settings → MCP to check the connection and enable tools.

Tested environments and browser compatibility

  • Tested environments:
    • Linux: standard distributions (x86_64 and ARM) with Python 3.10+. Command execution uses an interactive persistent bash session.
    • Windows: Windows 10 and Windows 11 with PowerShell and the py launcher. Command execution natively adapts to PowerShell preserving directory and environment variables.
    • Android + Termux: Termux environment with the python package. Opens URLs with termux-open-url. Playwright cannot currently be used on Termux, so browser_action and Playwright MCP are not available.
  • Browser compatibility:
    • ZeroChat does not work with the WebKit engine due to its local network access (Private Network Access) and web storage restrictions. Opening ZeroChat with WebKit redirects you to this section.
    • This affects Safari (macOS) and every browser on iPhone and iPad, including Chrome, Firefox and Edge for iOS/iPadOS, because Apple requires WebKit on those systems.
    • On Linux and Windows it works with Firefox or Chromium-based browsers (Chrome, Edge, Brave…). On macOS it should work the same, but it has not been tested.
