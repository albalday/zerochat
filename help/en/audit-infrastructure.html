Review 1: Infrastructure and rules

Which AGENTS.md rules are protected by a test, and which depend only on someone reading them? Updated on 16 October 2026.

Scope and method

Review of version 9.2.3 on the dev branch (commit 924aef6), examining all changes accumulated since the 9.1.0 audit to date. Follows the docs/audits/AuditFull.md procedure.

The criterion follows the 9.0.0 lesson: a rule only counts as met if a test fails when it is broken. Each claim states its source:

  • [test] an automated test protects it;
  • [cmd] a reproducible command checks it today, but nothing stops it from breaking;
  • [reading] code review, with no test or command;
  • [no test] a written rule that no test watches.

3. Local server security

  • Mandatory session token on all backend requests. [test] test_local_server.js
  • Daily token in ~/zerochat/config/token.json with 0600 permissions and 0700 directory. [test] test_backend_runtime.js (skipped on Windows)
  • Loopback listening by default, with an alert when configured for a non-local host. [test] test_backend_runtime.js
  • HMAC signature for each tool call with a single-use nonce. [test] test_local_server.js
  • Bounded commands: 30 s default, 600 s maximum, and process tree termination; Job Object on Windows. [test] test_backend_runtime.js; the Job Object test only runs on Windows and was skipped here
  • JavaScript sandbox: opaque-origin iframe with CSP connect-src 'none'; not a security barrier, as stated in help docs. [test] test_sandbox.js and browser_sandbox_security.test.js
  • Tool permissions: ask, allow_all, and workspace_trust policies, directory rules and authorized commands with path traversal blocking. [test] test_tool_security.js
  • SSRF protection and URL/MIME validation: in web downloads of documents (download_doc) and images (download_image). [test] test_fetch_page.js and test_image_fetcher.js

6. Assessment

Solid and well-protected infrastructure. Development from 9.1.0 to 9.2.3 has reinforced quality standards: adding office document ingestion, native XLSX parsing, multimodal vision tools, and automated project memory was completed without accumulating technical debt, adhering to the single source of truth rule and introducing boundary tests for every new capacity limit.
