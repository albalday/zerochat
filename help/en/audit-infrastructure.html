4. Security and isolation

  • External HTML: the ChatUtils primitives (setText, appendTextElement) have escaping tests. [test] That every innerHTML use is sanitized: [unverified] exhaustively.
  • JavaScript sandbox: <iframe> with sandbox="allow-scripts", CSP connect-src 'none', time watchdog and e.source filter. [read] The module itself warns that it is not a security sandbox at operating-system level (js/sandbox.js:11-14).
  • Daily token: ~/zerochat/config/token.json created with 0600 in a 0700 directory. [read] py/cc-environment.py
  • Tool signatures: HMAC-SHA256 over session, method, path, expiry, nonce and body hash; bounded TTL and single-use nonce under a lock. [read] py/ff-server.py:170-205
  • Processes: _kill_process_tree() kills the process group on timeout; MCP dependencies in ~/zerochat/.venv/. [read]
